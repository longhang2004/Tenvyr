## Delivered Architecture and Endpoints

1. **`ReviewDecisionService.decide` & `POST /api/v1/reviews/{id}/decisions`**:
   - Only `REVIEWER` distinct from request owner can decide on `COMPLETED` execution with valid verified report.
   - Lock order: operation advisory lock `(actorId, "DECIDE", idempotencyKey)` -> request row lock `FOR UPDATE` -> engine attempt/step/execution lock order.
   - Atomically records one decision and one `DECIDE` audit entry. Recheck actor enabled and role in TX.
   - First valid decision returns 201 Created with Location header. Equivalent replay returns 200 OK. Changed payload or duplicate key on different request returns 409 `IDEMPOTENCY_CONFLICT`. Parallel conflicting verdicts produce one winner (201) and one conflict (409).
   - Engine `ApprovalService` is never called; engine execution terminal state remains unmodified.

2. **`ReviewDecisionService.cancel` & `POST /api/v1/reviews/{id}/cancel`**:
   - Only owner `SUBMITTER` can cancel an execution in `PROCESSING` state (`PENDING` or `RUNNING`).
   - Lock order: advisory lock `(actorId, "CANCEL", idempotencyKey)` -> request row lock `FOR UPDATE`.
   - Invokes existing `cancelExecutionWithManager` on the SAME connection.
   - Re-reads authoritative execution state: if concurrent completion won, rolls back `CANCEL` audit and returns 409 Conflict.
   - Writes `CANCEL` audit row only when cancellation actually won.
   - Same-key replay returns 200 with stored outcome. Cross-request same-key replay returns 409 Conflict.

3. **`ReviewDecisionService.audit` & `GET /api/v1/reviews/{id}/audit`**:
   - Keyset-paginated ascending: `createdAt ASC, id ASC` with limit 1..100.
   - Reapplies SQL query visibility on every page: owner `SUBMITTER` and `REVIEWER` can read; foreign submitters receive 404 `NOT_FOUND` on first page and with cursor.
   - Exposes only `{id, actorId, action, createdAt}`, strictly excluding source code, comments, reports, and secrets.
   - Durable command deduplication prevents duplicate success audits on replays; failed/conflicting commands produce no success audits.

# T00 Task Report: Reusable Engine Composition and Pooled JDBC Seam

## Summary

Task T00 extracted the reusable engine composition into `ControlPlaneRuntime` and added the pooled connection seam `Db.fromDataSource(javax.sql.DataSource)`.

## Delivered Changes

1. `Db.fromDataSource(javax.sql.DataSource source)`:
   - Added `javax.sql.DataSource` support to `Db`.
   - Connections borrowed per operation or transaction and initialized with `SET TIME ZONE 'UTC'`.
   - Borrowed connections returned (closed) on statement completion, statement failure, and UTC initialization failure without leaking.
   - If closing the connection fails during UTC initialization failure cleanup, the original `SQLException` is preserved and the close failure is attached as a suppressed exception via `addSuppressed`.
   - Caller-owned transactions via `Db.on(Connection)` preserve connection ownership across errors (no commit, rollback, or close by `Db`).
   - Closing `Db` preserves caller-owned `DataSource`.

2. `ControlPlaneRuntime`:
   - Extracted composition graph from `Main`.
   - Accessors: `pipelines()`, `executions()`, `engine()`, `callbacks()`, `events()`.
   - Lifecycle: `startAfterMigrations()` and `close()`.
   - Legacy routes adapter: `registerLegacyRoutes(Http)`.
   - Preserves resource boundaries: does not own caller's `Db` or HTTP server admission.

3. `Main`:
   - Refactored to delegate composition, routes, and background lifecycle to `ControlPlaneRuntime`.
   - Constructor resource safety: ensures `ControlPlaneRuntime` validates configuration before binding and cleans up any partially acquired resources (`http`, `runtime`) with suppressed exceptions if construction fails, preventing socket port leaks before `start()`.
   - Retains ownership of `Http` server and caller `Db`.

4. Test Suite Enhancements & Harness Calibration:
   - `FoundationCheck`: validates `Db.fromDataSource`, pooled connection borrow/return, UTC session setup, failure cleanup, caller-owned rollback, pooled transaction commit/rollback recording, and UTC init + close failure error preservation (`addSuppressed`).
   - `ControlCheck`: validates `ControlPlaneRuntime` class presence, constructor, accessors, routes registration, lifecycle (close twice, start-after-close rejection), and constructor port-release regression test using an ephemeral port.
   - `ControlIntegrationCheck`: validates real PostgreSQL pooled borrow, dedicated probe table rollback with `DeliberateRollbackMarker`, real pooled transaction rollback, connection preservation, and `ControlPlaneRuntime` lifecycle against disposable schema `tenvyr_agy_t00_test`.
   - Sequential fixture architecture: `assertStandaloneRuntimeLifecycle()` executes sequentially after the outer fixture closes and drops its disposable schema, ensuring clean schema isolation for `Migrator.migrate()` without `uuid-ossp` collision.
   - Harness calibration: calibrated `assertOriginalReadModels` with optional `TENVYR_ORACLE_TIMEOUT_SECONDS` (default 20s, valid range 1..180s) to account for measured 86.206s cold TypeScript module initialization overhead on local NTFS/WSL (`oracle-module-warmup.log`).

# T01 Task Report: Isolated Spring Application, Signed Callbacks and Lifecycle Gates

## Summary

Task T01 is completed and accepted on 2026-11-13. The isolated Spring Boot application (`review-api`), lifecycle gates, and signed callback boundary reuse the accepted T00 `ControlPlaneRuntime` and pooled `Db.fromDataSource`. Final verification passed 11 unit tests and 13 integration tests, including repaired JDBC routing-query and fragment guards. Business schema, authentication, and review routes remain assigned to T02–T04.

## Delivered Changes

1. **Module Scaffolding (`backend/review-api/pom.xml`)**:
   - Spring Boot starter parent 3.5.16, Java 17, explicit internal artifact dependencies (`platform:0.1.0`, `control-plane:0.1.0`).
   - Web, Validation, JDBC, Security, Actuator, and PostgreSQL driver starters.
   - Surefire unit configuration (`failIfNoTests=true`, `*Test.java`).
   - Failsafe integration profile `review-integration` (`failIfNoTests=true`, `*IT.java`).
   - Module registered in `backend/pom.xml` reactor without altering root dependency management.

2. **Spring Application Entrypoint (`ReviewApplication.java`)**:
   - Annotated with `@SpringBootApplication` in package `io.tenvyr.review`.

3. **Engine Configuration (`EngineConfiguration.java`)**:
   - Injects Spring Boot autoconfigured `DataSource` (`HikariDataSource`) with pool size 10, acquisition timeout 2,000 ms, and UTC connection initialization.
   - Provides `@Bean(destroyMethod = "close") public ControlPlaneRuntime engineRuntime()`.
   - Bridges Spring environment and process environment to `AgentTransportConfig`.
   - Rejects explicit nonblank `KAFKA_BROKERS`, `ORCHESTRATOR_EVENT_TOPICS`, and `ORCHESTRATOR_RESULT_TOPICS`, configured Kafka agents (`transport.hasKafkaAgents()`), and non-HTTP `code-reviewer` configurations before allocating runtime resources.

4. **Lifecycle Coordination (`EngineLifecycle.java`)**:
   - Implements Spring `SmartLifecycle` at phase 100 (< `Integer.MAX_VALUE - 2048`).
   - Executes base database migrations (`Migrator.migrate(db)`) before runtime start.
   - Starts engine runtime (`startAfterMigrations()`) before web server admission.
   - Drains and closes engine runtime on shutdown after web admission stops. Startup cleanup attaches engine-close failures as suppressed exceptions; Spring owns destruction of the Boot-autoconfigured pool after dependent beans, including when another cleanup throws.

5. **Signed Callback Controller (`AgentCallbackController.java`)**:
   - Maps `POST /internal/agent-callbacks/http/code-reviewer`.
   - Enforces raw bounded streaming body <= 1 MiB (1,048,576 bytes), rejecting overflow with exact 413 Payload Too Large.
   - Extracts raw HMAC headers matching [HttpAgentAdapter](../../../../../backend/control-plane/src/main/java/io/tenvyr/control/engine/HttpAgentAdapter.java) wire constants (`KEY_ID`, `TIMESTAMP`, `DELIVERY_ID`, `SIGNATURE`) and delegates verification to `HttpAgentAdapter.handleCallback` under the [HTTP adapter wire contract](../../../../architecture/transports/http-agent-adapter-v1.md).
   - Maps successful handling to 204 No Content; delegates rejection mapping via `HttpAgentAdapter.callbackStatus`.

6. **Security Configuration (`ReviewSecurityConfiguration.java`)**:
   - Strict CSRF exemption solely for `POST /internal/agent-callbacks/http/code-reviewer`.
   - Enforces CSRF on all callback-adjacent unsafe routes, returning 403 Forbidden.
   - Permits actuator liveness and readiness health probes without credentials.
   - Denies all legacy routes (`/pipelines`, `/executions`) and unopened business routes with 401/403 JSON responses.
   - Disables form login and basic auth, silencing auto-generated default passwords.

7. **Focused Test Runner (`scripts/review-checks.sh`)**:
   - Supports `unit` and `integration` modes via Maven reactor `-pl review-api -am`.
   - Validates the PostgreSQL JDBC scheme, host, and disposable database name using the standard Node parser. Rejects routing query keys/aliases and raw `#` fragments; permits normal options such as `sslmode`/`currentSchema` and IPv6 hosts.
   - Emits safe generic error messages with no URL, credential, or database name leakage.

8. **Test Fixtures and Verification Gates**:
   - `ReviewContractCompatibilityTest`: verifies Jackson 2.21 family convergence, 200+ canonical Node golden vectors, immutable HMAC conformance vectors from `vectors.json`, production symbol contracts, database URL guard safety via real `ProcessBuilder` with an `@TempDir` fake Maven sentinel, both direct IT URL guards, and explicit Kafka config rejection.
   - `ReviewCallbackIT`: verifies HMAC authentication with real materialized invocations, exact raw-byte acceptance (204), tampered byte rejection (401), expired timestamp rejection (401), unsigned rejection (401), chunked streaming 413 without Content-Length, callback-adjacent CSRF 403, and actuator probe credential safety. Uses `@DynamicPropertySource` and `@DirtiesContext`.
   - `ReviewLifecycleIT`: verifies `SmartLifecycle` phase ordering, lock-held shutdown coordination with `pg_locks` against real PostgreSQL `step_attempts` AccessShareLock, pool closing sequencing, startup failure cleanup with initializer-registered `BeanPostProcessor` capture, and pool closure after other cleanup failure. Uses dedicated explicit operator config.

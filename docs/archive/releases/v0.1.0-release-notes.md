# Tenvyr v0.1.0 release notes

> Release-candidate artifact, not evidence of a published release. Final release
> remains blocked by the owner's license decision and merged-main verification.

Tenvyr supervises Python, TypeScript, and Java-backed agents as persisted
workflow steps. v0.1.0 combines standardized contracts, Kafka and HTTP dispatch,
retries, timeouts, idempotency, signed callbacks, and a dashboard that explains
each execution.

## Added

- Versioned `AgentInvocationV1` and `AgentResultV1` contracts.
- TypeScript and Python Worker SDKs with private package verification.
- Java Runner selection for mock, OpenAI, Anthropic, and Ollama.

## Changed

- Provider failure handling is explicit: `fail` or labeled deterministic mock.
- Current, roadmap, and historical documentation now have separate lifecycles.

## Fixed

- Cross-language JSON validation, callback timing, retry handling, and result
  correlation were hardened with shared conformance evidence.

## Security

- HTTP callbacks are HMAC-signed, timestamped, replay-checked, and bounded.
- Dashboard JSON previews redact sensitive keys before display.

## Showcase

- Offline mock is the default and requires no provider key.
- `pnpm showcase:up` and `pnpm showcase:smoke` exercise success and retry-once
  through a Python Worker and Java-backed quality gate.
- See the [quick start](../../../README.md),
  [demo guide](../../showcase/demo-guide.md), and
  [case study](../../showcase/case-study.md).

## Known limitations

- Worker queue, idempotency, callback, and replay state are process-local; there
  is no crash durability or multi-process coordination.
- Cancellation is cooperative. Provider integration is an application/runtime
  responsibility. Java Runner token usage may be estimated.
- Compatibility identifiers remain unchanged.
- Packages are private and unpublished; npm/PyPI releases do not exist.

## Not included

No universal LLM gateway, model routing, provider registry, fallback chain,
policy engine, artifact store, durable outbox, OpenTelemetry integration,
framework adapter suite, protocol v2, npm publication, or PyPI publication.
